# Проект автоматизации тестирования сервиса Яндекс Самокат.
Данный проект содержит автоматизированные тесты для сервиса Яндекс Самокат с использованием фреймворка Pytest и инструмента Selenium WebDriver. В проекте реализован паттерн проектирования Page Object Model для разделения логики тестов и структуры страниц.

## Основа для написания автотестов 
* **Pytest** — фреймворк для написания и запуска тестов
* **Selenium WebDriver** — инструмент для автоматизации действий в браузере
* **Allure Framework** — генерация подробных отчетов о тестировании

## Структура проекта
```text
.
├── allure-report/             # Статический HTML-отчет (сгенерирован локально)
├── data/
│   └── data.py                # Тестовые данные (тексты ответов, параметры заказов) и базовые URL
├── pages/
│   ├── main_page.py           # Локаторы и методы для работы с главной страницей
│   └── order_page.py          # Локаторы и методы для работы со страницей оформления заказа
├── tests/
│   ├── test_main_page.py      # Тестирование «Вопросы о важном»
│   └── test_order_page.py     # Тестирование сценариев заказа и редиректов в хедере
├── conftest.py                # Конфигурация Pytest и фикстуры браузера
└── requirements.txt           # Список зависимостей проекта
```

## Покрытие тест-кейсов
* **Главная страница:**
    * **Тест «Вопросы о важном»:** Проверяет, что при клике на каждый из 8 вопросов открывается соответствующий блок с корректным текстом ответа. Тест параметризован по индексам элементов (от 0 до 7).
* **Страница Заказа:**
    * **Позитивный сценарий оформления заказа:** Параметризованный тест, который проверяет весь позитивный сценарий заказа самоката через обе доступные точки входа (кнопка «Заказать» в хедере страницы и кнопка в середине страницы). Проверяется успешное заполнение форм «Для кого самокат», «Про аренду» (с выбором цвета и без) и появление модального окна успешного оформления заказа.
    * **Редиректы в хедере:** Проверка клика по логотипу «Самокат» (должен вести на главную страницу Самоката) и по логотипу «Яндекс» (должен перенаправлять на главную страницу Дзена в новой вкладке).

## Требования
* Python 3.x
* Mozilla Firefox
* Allure Framework

## Установка зависимостей
Перед запуском убедитесь, что у вас установлены все необходимые библиотеки
```bash
pip install -r requirements.txt
```

## Запуск тестов
```bash
pytest -v
```

## Запуск тестов с генерацией Allure-отчета
Запуск тестов и запись логов в папку allure-results/
```bash
pytest --alluredir=allure-results
```

Просмотр локального отчета в браузере
```bash
allure serve allure-results
```
